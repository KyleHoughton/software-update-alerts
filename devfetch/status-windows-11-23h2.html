Current status as of November 10, 2026  

Windows 11, version 23H2 Enterprise and Education editions have reached end of updates. The November 2026 Windows security update is the last update available for these editions. Devices running these editions will no longer receive monthly security updates containing protections against the latest security threats. We recommend updating eligible devices to Windows 11, version 26H2 to continue receiving monthly security and quality updates.

To check whether an update is available for your eligible device, select Settings > Windows Update, then select Check for updates. If the update is available for your device, select Download and install.

Windows 11, version 23H2 Home and Pro editions reached end of updates on November 10, 2025.

SQL Server linked server connections might remain open

StatusOriginating updateHistory
ConfirmedOS Build 22631.7652
KB5126653
2026-10-13		Last updated: 2026-11-23, 18:35 PT
Opened: 2026-11-11, 15:11 PT

After Windows updates released October 13, 2026 (KB5126653), and later are installed on server devices, connections created by SQL Server linked server queries might remain open after the queries complete. As additional queries are performed, connections to external databases can accumulate instead of closing as expected. This can slow or degrade server performance after prolonged run time.

This issue affects SQL Server linked server queries that use OLE DB providers to connect to external databases. Oracle and PostgreSQL connections are among those known to be affected. In affected environments, administrators might observe an increasing number of open connections to external databases, even when the associated SQL Server linked server queries are no longer running.

If idle connections can be identified, it is possible to manually close them in order to temporarily relieve server load. It is also possible to temporarily restore system stability by restarting the SQL service. However, these steps can also interrupt active queries or transactions, and the problem can resurface again after sufficient operation time.

Workaround: A mitigation is available for affected enterprise devices. To apply this mitigation in your organization, contact Microsoft Support for business.

Next steps: Microsoft is working on a resolution for this issue, which is planned for a future Windows update. Additional information will be shared as soon as it becomes available.

Affected platforms:

  • ​Client: Windows 11, version 26H2; Windows 11, version 26H1; Windows 11, version 25H2; Windows 11, version 24H2; Windows 11, version 23H2; Windows 10, version 1809; Windows 10 Enterprise LTSC 2019
  • ​Server: Windows Server 2025; Windows Server 2022; Windows Server, version 1809; Windows Server 2016; Windows Server 2012 R2; Windows Server 2012

USB audio devices might fail to start or produce no sound

StatusOriginating updateHistory
Resolved KB5131087OS Build 22621.7582
KB5122880
2026-09-08		Resolved: 2026-11-10, 10:00 PT
Opened: 2026-11-09, 16:04 PT

After installing the September 8, 2026, Windows security update (KB5122880), some USB Audio Class 1.0 devices might fail to start or produce audio. Affected devices might experience one or more of the following symptoms: 

  • ​The device displays an error in Device Manager: "This device cannot start (Code 10).” 
  • ​No audio output.
  • ​Volume controls are unresponsive or remain at zero. 
  • ​Sound settings are unresponsive or unavailable. 
  • ​Some devices might function in standard stereo configurations but fail when using multichannel audio features, including 8-channel or 3D audio modes. Some customers have reported that they're able to restore audio in these cases by switching to 2-channel mode. (*Note: This behavior is resolved in the out-of-band update released on September 14, 2026. See Resolution section below.)

This issue is limited to USB Audio Class 1.0 devices.

Resolution: The symptoms experienced on devices using 8-channel or 3D audio modes (last bullet point in the list of symptoms documented in this entry) are resolved in the out-of-band (OOB) update released on September 14, 2026, and updates released after this date. The remaining symptoms are resolved in the Windows security update released on November 10, 2026 (KB5131087) and later updates. We recommend you install the latest security update for your device as it contains important improvements and issue resolutions, including this one. 

If you are an IT administrator that contacted Microsoft Support for Business to obtain an immediate workaround, you do not need to use the Known Issue Rollback (KIR) or special group policy to resolve this issue.

Affected platforms:

  • ​Client: Windows 11, version 26H2; Windows 11, version 26H1; Windows 11, version 25H2; Windows 11, version 24H2; Windows 11, version 23H2; Windows 10, version 22H2; Windows 10, version 21H2; Windows 10 Enterprise LTSC 2019; Windows 10 Enterprise LTSC 2016
  • ​Server: Windows Server 2025; Windows Server 2022; Windows Server 2019; Windows Server 2016; Windows Server 2012 R2; Windows Server 2012
