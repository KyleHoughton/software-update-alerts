Executive summary
This month at a glance
 Review advised
No actively exploited vulnerabilities affect Windows or SQL Server this month, but 1 known issue is still open. Review them before deploying. Microsoft released 7 Windows Server updates, 12 workstation updates and 10 SQL Server updates in November 2026, fixing 785 CVEs (36 critical).
Deployment advice
29 updates released in November 2026: 13 test first, 8 deploy, 5 superseded, 3 optional. Deploy means no known issues; Test first means Microsoft lists an open known issue, so pilot it; Hold means Microsoft advises against installing; Use KB… means a newer out-of-band update replaces it.
Out-of-band: Microsoft released out-of-band updates this month for Windows Server 2025, Windows Server 2022, Windows Server 2019, Windows 10 22H2, Windows 10 LTSC 2021. No further out-of-band update has been announced; Microsoft plans to fix the open issues in a future monthly update.
